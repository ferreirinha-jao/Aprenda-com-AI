Como criar um chatbot para WhatsApp com IA do zero

Ferramentas: n8n, Evolution API, ChatGPT

WhatsApp é o canal de comunicação mais usado no Brasil — e também onde a maioria das pequenas empresas perde leads por demorar para responder ou não ter processo de atendimento. Um chatbot com IA resolve isso: responde na hora, qualifica o lead e só transfere para o humano quando necessário.

Neste artigo você vai entender as opções disponíveis, a stack técnica mais usada por freelancers brasileiros e como montar um bot funcional do zero.

O que um chatbot de WhatsApp pode fazer

Antes de entrar na técnica, vale entender o que faz sentido automatizar — e o que ainda precisa de atendimento humano.

Atendimento 24/7
Automático

Responde mensagens fora do horário comercial com informações sobre produtos, preços, endereço e funcionamento.

Qualificação de leads
Automático

Faz perguntas para entender a necessidade, orçamento e urgência antes de repassar para o time comercial.

Agendamento
Automático

Verifica disponibilidade e confirma horários diretamente no WhatsApp, integrado ao Google Calendar ou Calendly.

FAQ inteligente
Automático

Responde perguntas frequentes com base em uma base de conhecimento específica do negócio.

Follow-up automático
Automático

Envia sequência de mensagens para leads que não responderam ou clientes que precisam de retorno.

Triagem para humano
Híbrido

Identifica quando a conversa precisa de atendimento especializado e transfere para o atendente certo com contexto.

Para quem está começando ou montando bots para clientes pequenos, a combinação n8n + Evolution API é a mais popular no Brasil: barata, flexível e sem depender de aprovação da Meta.

Aviso importante

A Evolution API usa a sessão do WhatsApp Web, não a API oficial da Meta. O número pode ser banido se o uso for muito agressivo (mensagens em massa, comportamento de spam). Use com moderação e sempre com opt-in dos contatos.

Passo a passo: montando o bot

1

Suba a Evolution API

A forma mais fácil é via Railway ou Render (ambos têm plano gratuito para começar). O repositório oficial tem um botão de deploy com 1 clique. Após subir, acesse o painel e crie uma instância.

2

Conecte o número de WhatsApp

Na Evolution API, gere o QR Code e escancie com o WhatsApp do número que será usado pelo bot. Recomendado: use um chip dedicado, separado do WhatsApp pessoal.

3

Configure o Webhook no n8n

No n8n, crie um novo workflow com um nó Webhook. Copie a URL gerada e configure na Evolution API para que cada mensagem recebida dispare esse webhook.

4

Processe a mensagem recebida

O webhook vai receber um JSON com os dados da mensagem. Extraia o número de quem mandou, o texto e a instância. Filtre para ignorar mensagens do próprio bot (echo).

5

Envie para o ChatGPT com contexto

Use o nó OpenAI (ou HTTP Request para a API) e passe a mensagem com um system prompt que define a personalidade e o conhecimento do bot. Inclua o histórico de conversa para o bot ter memória.

6

Envie a resposta de volta

Com a resposta do ChatGPT em mãos, faça um HTTP Request para a Evolution API com o endpoint de envio de mensagem, passando o número do destinatário e o texto gerado.

O system prompt faz toda a diferença

O comportamento do bot depende diretamente do prompt de sistema. Um prompt mal feito resulta num bot que inventa informações, foge do assunto ou responde de forma estranha.

System prompt — Bot de atendimento para clínica
Você é a assistente virtual da [Nome da Clínica], uma clínica de [especialidade] localizada em [cidade]. Seu nome é [nome do bot] e você atende pelo WhatsApp. SEU PAPEL: - Responder dúvidas sobre serviços, preços e funcionamento da clínica - Ajudar pacientes a agendar consultas - Encaminhar casos urgentes ou complexos para atendimento humano INFORMAÇÕES DA CLÍNICA: - Serviços: [liste os serviços] - Preços: [liste ou diga que depende de avaliação] - Horário de atendimento: [dias e horários] - Endereço: [endereço completo] - Para agendar: [instrução de como agendar] REGRAS IMPORTANTES: - Nunca invente informações. Se não souber algo, diga que vai verificar e peça contato. - Não faça diagnósticos médicos. Apenas informe sobre os serviços. - Se a pessoa estiver em emergência, oriente a ligar para o SAMU (192) imediatamente. - Se a conversa precisar de atendimento humano, diga: "Vou te conectar com nossa equipe agora." - Seja cordial, use linguagem simples e evite termos técnicos. Responda sempre em português do Brasil, de forma direta e amigável.
Prompt para criar system prompt personalizado
Preciso criar um system prompt para um chatbot de WhatsApp. Informações do negócio: - Tipo de empresa: [ex: academia, imobiliária, pet shop] - Nome da empresa: [nome] - Cidade: [cidade] - Serviços oferecidos: [liste] - Preços (se puder compartilhar): [preços ou "variam"] - Horário de funcionamento: [horário] - Tom de comunicação desejado: [ex: formal, descontraído, amigável] Crie um system prompt completo para o ChatGPT que: 1. Define a personalidade e o papel do bot 2. Inclui as informações do negócio de forma estruturada 3. Define regras claras do que o bot pode e não pode fazer 4. Instrui quando transferir para atendimento humano 5. Garante respostas em português do Brasil O prompt deve evitar que o bot invente informações e mantenha foco no negócio.

Como adicionar memória de conversa

Por padrão, cada mensagem enviada ao ChatGPT é tratada como nova conversa — o bot não lembra o que foi dito antes. Para resolver isso, você precisa armazenar o histórico.

1

Armazene cada mensagem em banco de dados

Use o nó do Redis, SQLite ou Supabase no n8n para salvar cada mensagem com o número do contato, o texto e o papel (user/assistant). Redis é o mais rápido para esse uso.

2

Recupere as últimas N mensagens

Antes de enviar para o ChatGPT, busque as últimas 5 a 10 mensagens daquele número. Limite o histórico para não estourar o contexto da API.

3

Monte o array de mensagens

Formate as mensagens no padrão da OpenAI: array com objetos {role: "user"/"assistant", content: "texto"}. Adicione a nova mensagem do usuário ao final antes de enviar.

Alternativas mais simples para começar

Se a stack n8n + Evolution API parece complexa demais para um primeiro projeto, existem alternativas que entregam um bot funcional mais rápido.

ManyChat
Pago

Interface visual para criar fluxos. Integra com WhatsApp Business oficial. Bom para fluxos simples sem necessidade de IA generativa.

Typebot
Open sourceGratuito

Cria fluxos de conversa visuais com blocos. Tem integração com OpenAI. Pode ser embedado em sites além do WhatsApp.

Zapi
Pago

API brasileira para WhatsApp. Mais estável que Evolution para quem quer foco no produto sem gerenciar infraestrutura.

Flowise

Builder visual de agentes de IA. Integra com WhatsApp via webhook. Ótimo para bots com RAG (base de conhecimento).

Erros comuns ao criar chatbots de WhatsApp

Bot que inventa informações

Sem instrução clara no system prompt, o ChatGPT vai "alucinar" preços, endereços e serviços. Sempre defina: "Se não souber, diga que vai verificar."

Sem transferência para humano

Um bot que tenta resolver tudo e nunca transfere frustra o cliente quando o problema é complexo. Defina gatilhos claros para escalar para atendente.

Número principal usado para o bot

Se o número for banido pela Evolution API, o cliente perde o contato comercial. Sempre use um número dedicado para o bot.

Sem limite de histórico

Enviar todas as mensagens de uma conversa longa para a API é caro e pode ultrapassar o limite de tokens. Limite a 10 mensagens ou use resumo.

Bot sem personalidade definida

Um bot genérico que poderia ser de qualquer empresa não passa credibilidade. Dê um nome, um tom e uma identidade alinhada com a marca do cliente.

Quanto cobrar por um chatbot para cliente?

O mercado brasileiro pratica entre R$ 1.500 e R$ 5.000 para desenvolvimento de um bot básico, mais uma mensalidade de R$ 300 a R$ 800 para manutenção e hospedagem.

O valor aumenta com a complexidade: integrações com CRM, múltiplos fluxos, base de conhecimento com RAG e dashboards de analytics. Um bot bem documentado que você consegue replicar para outros clientes do mesmo segmento é o melhor produto que você pode ter.

Por onde começar

Monte o bot primeiro para você mesmo ou para um amigo com um negócio. Teste o fluxo completo, encontre os problemas e documente o processo. Esse projeto piloto vira o caso de portfólio e a base técnica para os próximos clientes.
