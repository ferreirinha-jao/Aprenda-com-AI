# Guia de publicação — Ganhar Dinheiro com IA

Esta pasta organiza artigos sobre monetização, serviços e produtos que usam inteligência artificial.

## Estrutura

```text
content/ganhar-dinheiro-com-ia/
├── README.md
├── index.md
├── 01-3-negocios-de-ia-com-claude.md
└── 02-nome-do-proximo-artigo.md
```

## Como adicionar um artigo

1. Escolha o próximo número disponível, com dois dígitos: `02`, `03`, `04`.
2. Use um slug curto, em minúsculas, sem acentos e separado por hífen. Exemplo: `02-validar-um-micro-saas-com-ia.md`.
3. Comece com um único título Markdown de nível 1 (`#`). Organize o restante com subtítulos (`##` e `###`), listas e blocos de código quando forem úteis.
4. Inclua exemplos verificáveis, limites, custos e riscos relevantes. Identifique estimativas financeiras como hipóteses, não garantias.
5. Não inclua credenciais, dados pessoais ou informação de clientes sem autorização.
6. Depois de criar o artigo, edite manualmente a secção **Artigos** em `index.md`: acrescente o número, o título e o link relativo para o arquivo.
7. Confirme que o link abre o arquivo correto e que a sequência numérica não foi duplicada.

## Atualização do sumário

O índice desta pasta é uma lista Markdown mantida manualmente; não existe um gerador automático configurado para esta secção. Portanto, cada novo artigo deve ser adicionado também à lista **Artigos** de `index.md`. Não altere configurações globais ou dependências para publicar um artigo nesta coleção.
